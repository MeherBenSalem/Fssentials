# Contributing to Donut Essentials

Thank you for your interest in improving Donut Essentials!

## How to contribute

1. **Fork** this repository on GitHub.
2. **Create a branch** for your change (`git checkout -b feature/my-improvement`).
3. **Make your changes** with clear commits and focused diffs.
4. **Run tests** before opening a pull request:
   ```bash
   mvn test
   ```
5. **Open a pull request** against the default branch with a short description of what changed and why.

## Guidelines

- Match existing code style and patterns in the project.
- Keep pull requests focused; unrelated refactors are better as separate PRs.
- Update user-facing docs (README, CHANGELOG) when behavior or requirements change.
